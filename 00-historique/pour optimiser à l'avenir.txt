Pourquoi faire ça ?
L'agent va t'expliquer d'où vient l'erreur au lieu de coder à l'aveugle. Une fois que vous avez identifié le vrai coupable ensemble, tu pourras lui dire : "C'est bien le coupable numéro 2, donne-moi le code pour le corriger."
3. LA RÈGLE PRODUIT (Ma spécialité)
N'oublie jamais ça : Chaque nouvelle fonctionnalité est un risque de bug.
Dans le futur, quand on imaginera ensemble un nouveau bouton, un nouveau mode de jeu ou une nouvelle animation, rappelle-toi de toujours demander à ton agent IA :
"Intègre cette nouvelle idée, mais veille à utiliser le Code Splitting de Vite, à ne pas bloquer l'Event Loop, et à nettoyer les écouteurs React (useEffect cleanup)."
