# Enregistrement de l'historique des modifications
- Toujours décrire les changements effectués avec des phrases simples et claires.
- Ajouter ces descriptions dans un fichier Markdown (.md) nommé strictement selon le format `historique_YYYY-MM-DD.md` (ex: `historique_2026-08-31.md`) sauvegardé dans le dossier `00-historique/`.
- Inclure systématiquement la date et l'heure pour chaque entrée d'historique.
- Si le dossier `00-historique` ou le fichier Markdown du jour n'existe pas, le créer automatiquement (un seul fichier par jour).
- Ne pas sauvegarder les changements qui ne touchent pas le code (comme les lancements locaux ou lectures de fichiers).
